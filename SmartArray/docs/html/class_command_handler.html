Detailed Description

template<typename T, typename Parser>
class CommandHandler< T, Parser >

Handles commands for a SmartArray using a specified parser.

This template class is responsible for processing command-line arguments, creating the appropriate command via CommandFactory, and executing it.

Template Parameters
TType of elements stored in SmartArray
ParserParser type used to parse input arguments into objects of type T

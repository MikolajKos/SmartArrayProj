Detailed Description

template<typename T, typename Parser>
class AddCommand< T, Parser >

Command to add a new element to a SmartArray.

This template class implements the Command interface and allows adding elements to a SmartArray using a specified parser for input arguments.

Template Parameters
TType of elements stored in SmartArray
ParserParser type used to parse command-line arguments into objects of type T

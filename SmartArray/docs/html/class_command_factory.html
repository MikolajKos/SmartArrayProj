Detailed Description

template<typename T, typename Parser>
class CommandFactory< T, Parser >

Factory class to create command objects.

This template class maps command names to their corresponding Command objects and provides a method to create commands dynamically based on a string identifier.

Template Parameters
TType of elements stored in SmartArray
ParserParser type used to parse input arguments into objects of type T

Detailed Description

template<typename T, typename Parser>
class HelpCommand< T, Parser >

Command to display help information for SmartArray CLI commands.

This template class implements the Command interface and provides detailed usage instructions for all commands, or for a specific command if a name is passed as an argument.

Template Parameters
TType of elements stored in SmartArray
ParserParser type used to provide description of the element type T

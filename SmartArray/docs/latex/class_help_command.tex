class Help\+Command$<$ T, Parser $>$}
\doxylink{class_command}{Command} to display help information for \doxylink{class_smart_array}{Smart\+Array} CLI commands. 

This template class implements the \doxylink{class_command}{Command} interface and provides detailed usage instructions for all commands, or for a specific command if a name is passed as an argument.
